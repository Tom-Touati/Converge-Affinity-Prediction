# Antibody–antigen ΔΔG prediction on SKEMPI 2.0

A multimodal sequence-and-structure model for the change in antibody–antigen binding free
energy on mutation, on the antibody–antigen subset of SKEMPI 2.0.

**940 rows, 53 complexes, 32 of them with the five mutations needed to score a within-complex
correlation.** That number governs everything below: it is the reason the headline metric is
per-complex rather than pooled, the reason every claim carries a seed spread, and the reason
the best model is a random forest over 49 handcrafted columns rather than a deep fusion
network.

## Results

Grouped 5-fold cross-validation, **no complex shared between folds**. Every number is
regenerated by `make report` and `python scripts/final_table.py`; none was typed by hand.

```
model                                 ens  per seed  spread  n  neg    bal  bal-cal   stab
E0a_rf_handcrafted (chem+geom+MPNN) +0.381    +0.379   0.032  3    6  0.444    0.498   0.06
l1_gated        (ESM+MPNN, gated)   +0.300    +0.249   0.028  3    7  0.463    0.459   0.25
cat128_reg2_l1  (ESM+MPNN, concat)  +0.293    +0.239   0.063  3    6  0.439    0.457   0.19
st64_nopca_grouped                  +0.274    +0.274     -    1    6  0.508    0.506   0.48
gf_reg2         (heavier reg)       +0.270    +0.235   0.055  3    7  0.460    0.470   0.21
st64_film_struct (FiLM)             +0.227    +0.227     -    1    7  0.455    0.448   0.29
st64_noattn     (no fusion control) +0.212    +0.212     -    1    9  0.392    0.423   0.13
st64_xattn_rev_nopca (cross-attn)   +0.204    +0.182   0.046  3    9  0.454    0.445   0.35
[complex mean only] — the floor     +0.000                         0.580            0.58
```

`ens` averages the seeds then scores once — what you would ship. `per seed` scores each seed
separately — what one training run gives you. **`spread` is max − min across seeds, and it is
the number to read every comparison against.** Reporting only one of these is how a model
appears to gain 0.05 by being written up differently: `l1_gated` is +0.300 as an ensemble and
+0.249 as the mean of its seeds, from the same predictions.

`bal` is balanced 3-class accuracy (classes are 13 / 34 / 53 %, so plain accuracy rewards
guessing the majority). `bal-cal` is the same after quantile calibration. `stab` is recall on
**stabilising** mutations — the class antibody engineering actually cares about.

Two rows deserve attention before the winner does.

**The floor.** Predicting each complex's own mean ΔΔG — a model that never looks at the
mutation — scores **+0.672 pooled Pearson, 1.144 RMSE, and 0.580 balanced accuracy**, beating
every model here on all three. It scores **+0.000** per complex. Between-complex variance
dominates this dataset, so pooled correlation, RMSE and accuracy mostly measure whether a
model can identify the complex. That is why they are not the headline, and why
`report_runs.py` prints this floor beneath every comparison.

**The no-fusion control** (`st64_noattn`, +0.212) is the same network with the structure
branch deleted. Most of the fusion mechanisms below do not beat it.

### On the homology split

`frozen5` withholds whole complexes. The project's `cluster` split withholds whole homology
clusters, which is the harder and more honest test. Three seeds each, per-complex Spearman:

| model | by complex | by cluster | retained |
| --- | --- | --- | --- |
| random forest, 49 handcrafted columns | 0.418 | **0.224** | 54 % |
| random forest, pooled ESM + ProteinMPNN | 0.366 | 0.182 | 50 % |
| our best network | 0.246 | 0.084 | **34 %** |

Everything degrades; the network degrades most, and 11 of its complexes end with a *negative*
within-complex correlation. The embedding models were leaning on homology that the cluster
split withholds. This is the strongest single argument in the repository for the handcrafted
features, and it is why "use a bigger encoder" does not appear in the next steps.

## The model, and why it is this one

**`E0a_rf_handcrafted` — a random forest over 49 columns spanning both modalities:**

| block | what it is | modality |
| --- | --- | --- |
| substitution chemistry, 26 cols | hydrophobicity, volume, charge, polarity deltas; BLOSUM; position | sequence |
| interface geometry | relative SASA, burial, contact counts at the mutated residue | structure |
| ProteinMPNN | inverse-folding log-likelihoods for wild-type and mutant residue | structure |

Per-complex Pearson **+0.381** (3-seed ensemble), Spearman **0.418**, seed spread 0.032.

**Why a forest rather than the neural fusion model.** The gap is +0.381 against +0.300 — about
2.5× the seed spread, so it is one of the few differences in this project that clears the
noise. The forest also retains 54 % of its score under the homology split where the network
retains 34 %. On 752 training rows per fold, 49 informative columns and an ensemble of shallow
trees is simply the better-matched hypothesis class.

**Why these features are genuinely multimodal.** Chemistry describes the substitution;
geometry and ProteinMPNN describe the site it happens at. Per-complex Spearman, 3 seeds,
940 rows:

| features | modalities | per-cx ρ |
| --- | --- | --- |
| pooled ESM only | sequence | 0.273 |
| pooled ESM + ProteinMPNN | sequence + structure | 0.366 |
| chemistry + geometry + ProteinMPNN | sequence + structure | **0.418** |

Adding the structure encoder to pooled sequence embeddings is worth **+0.093**, well clear of
the 0.032 seed spread. That is the justification for fusing — a measured delta against the
single-modality control, rather than "it is multimodal".

> The earlier version of this README quoted paired-bootstrap intervals for chem → chem+geom
> and friends. Those were computed on 997 rows, before censored affinities were dropped, and
> the rung-level predictions needed to regenerate them on the current 940 rows are no longer
> in the repository. They have been replaced by the table above rather than restated.

### The defect in it, and the fix

The forest predicts *stabilising* for **3 % of rows when the truth is 13 %** — it finds 7 of
126, recall **0.06**. It wins the ranking metric while being nearly blind to the class that
matters for design.

This is a **thresholding artifact, not a modelling failure.** The forest compresses toward
the mean (§1 of the error analysis), so its predictions rarely fall below −0.5, and cutting at
the *label* edges then starves the stabilising class. Cutting at its own quantiles instead:

```
forest, label edges          balanced 0.439   recall  0.06 / 0.52 / 0.74
forest, quantile-calibrated  balanced 0.500   recall  0.29 / 0.50 / 0.71
per-complex Spearman  +0.3613 -> +0.3613      unchanged
```

Calibration is monotone, so the ranking cannot change — balanced accuracy and stabilising
recall improve at **zero cost**. **Ship the forest calibrated.** It still does not reach the
0.48 stabilising recall of `st64_nopca_grouped`, so if the downstream task is *finding*
affinity-improving mutations rather than ranking known ones, the network is the better choice
and the table above says so.

## Multimodal fusion: what was tried

The interesting result is negative, and it is only interpretable because the control exists.

Sequence: ESM-2 650M per residue. Structure: ProteinMPNN `encoder_h_V` per residue. Both
cropped to the interface (<12 Å) ∪ site neighbourhood (<10 Å) ∪ mutated ±2, median ~85
residues. The mutation is represented as `site_mean(mutant) − site_mean(wild-type)` over the
mutated residues, with the mutant sequence re-embedded rather than edited in latent space.

| fusion mechanism | per-cx r | vs the no-fusion control (+0.212) |
| --- | --- | --- |
| gated fusion, vector gates over both modalities | **+0.300** | +0.088 |
| plain concatenation | +0.293 | +0.081 |
| FiLM on the structure delta | +0.227 | +0.015 |
| cross-attention, structure → sequence | +0.204 | −0.008 |
| cross-attention, sequence → structure | +0.199 | −0.013 |
| binding-area structure pool instead of site pool | +0.227 | +0.015 |

**Four of six mechanisms sit within the seed spread of the control.** Cross-attention over
ProteinMPNN — the most elaborate thing built — scores *below* a model with the attention
deleted. Removing the fold-local PCA so attention had raw embeddings to work with did not
rescue it.

Against all of that, **the largest single gain came from features, not architecture**: adding
26 substitution-chemistry columns to the same network moved it +0.191 → +0.266.

The practical conclusion is that on this dataset the fusion *mechanism* is not the binding
constraint, and a project that spends its budget searching architectures is optimising the
wrong thing. The evidence is in [ERROR_ANALYSIS.md §9–§10](ERROR_ANALYSIS.md); the full
catalogue of **45 completed configurations** — every family, config, parameter count and
result, including the two that are implemented but unmeasured — is
[docs/ARCHITECTURES.md](docs/ARCHITECTURES.md).

## Evaluation and error analysis

**[ERROR_ANALYSIS.md](ERROR_ANALYSIS.md)** is the substantive document. Part I covers the
forest's errors — compression toward the mean, blindness on the antibody side, multi-point
non-additivity, interface-location behaviour, the ten worst residuals. Part II covers errors
of the *measurement*, which turned out to matter more:

- **Pooled Pearson mostly measures complex identity** — the floor beats every model on it.
- **The noise floor exceeds most of the effects.** Seed spread reaches 0.117 per complex and
  0.376 pooled within a single fold. The whole architectural ladder fits inside it.
- **The networks ride homology; the forest less so** (34 % vs 54 % retained).
- **It is not a bookkeeping bug.** Across all 940 rows and 1,726 mutated sites: zero residue
  mismatches, and `‖t_mut − t_wt‖` puts the mutated sites in the top-k on 97 % of sides at a
  median of 22× the median residue. Run it with `make align`.
- **Capacity is not the limit.** Removing an entire head layer — 31 % of the parameters — cost
  nothing measurable.

Two conclusions in this project were drawn from partial folds and **reversed** when the last
fold landed. Both are recorded in [AI_PROMPTS.md](AI_PROMPTS.md) rather than quietly dropped.

## Limitations

1. **Data volume is the binding constraint.** 752 training rows per fold, 32 scorable
   complexes. The seed spread is what that looks like from the inside, and no regularisation
   setting removed it: raising dropout 75 %, noise 150 % and weight decay tenfold cost
   0.037–0.043 on two architectures and reduced variance on neither.
2. **Label noise caps the achievable correlation.** Within-complex label sd has a median of
   1.104 kcal/mol, and repeated (complex, mutation) measurements in SKEMPI disagree materially.
3. **Three complexes hold 24 % of the rows.** Any pooled statistic is partly about them.
4. **Pretrained sequence embeddings do not clear zero here**, across six probes and three
   protein language models. 26 chemistry columns outperform 1280-dimensional embeddings of the
   same mutation. AntiBERTy, antibody-specific, lost to ESM-2 by 0.046 on a matched control.
5. **Single structure per complex.** ProteinMPNN sees the wild-type backbone only; there is no
   mutant structure, so the structure branch is identical for every mutation of a complex.
6. **The cluster-split numbers are 4-fold, not 5** — the homology clustering yields 4 usable
   folds, so they are not directly comparable to the frozen5 column.

## Next steps, in the order I would do them

1. **Ship the forest calibrated** (done above, free) and report balanced accuracy alongside
   correlation everywhere. Any evaluation that omits it hides a 0.06-recall class.
2. **Give the network the forest's features.** The largest measured gain in the whole project
   came from adding 26 chemistry columns; the network currently has those but not interface
   geometry. That is the one untried lever with direct evidence behind it.
3. **Share the input-noise draw between the wild-type and mutant branches.** Measured with
   `audit_augmentation.py`: the noise is drawn independently per branch, so it compounds by
   √2 in the difference and reaches **0.8× the delta's own standard deviation** — at the
   heaviest setting tried, more noise than signal. Sharing the draw is a two-line change and
   would explain why more regularisation kept costing accuracy.
4. **Ordinal loss rather than MSE.** MSE asks the model to reproduce a value whose repeat
   measurements disagree by ~1.1 kcal/mol. A CORAL head (implemented, `ordinal=2`) asks which
   side of −0.5 and +0.5 a mutation falls on, driven by one shared scalar so the thresholds
   cannot contradict each other. Two extra parameters.
5. **Three seeds minimum for any future claim**, and report the spread. Half the comparisons
   in the published ΔΔG literature would not survive this.
6. **Blend the forest with a network.** They agree only 0.42–0.54 on which rows are hard, and
   a fixed 25 % blend lifts per-complex r from +0.397 to +0.418–0.424 across two different
   networks. The weight was not tuned on held-out data, so validate it properly — but this is
   better evidenced than any architecture change in the fusion ladder.
7. **Correct the shrinkage.** Signed error correlates with true ΔΔG at ρ ≈ −0.8 for every
   model, and with deviation from the complex's own mean at ρ ≈ −0.58. A monotone
   recalibration fitted on validation folds addresses information that is present and unused.
8. **More data before more architecture.** Everything above says the constraint is 752 rows,
   not the model. AB645/AB1101 rows are built and cached (`src/perturb/extra_rows.py`) with
   homology-model leakage removed; they have never been trained on.

## Setup and running

```bash
pip install -r requirements.txt          # Python 3.10; torch pinned, see requirements.txt
make data                                # SKEMPI -> data/processed/*.parquet  (~65 s)
make splits                              # frozen homology folds -> data/folds.csv  (~28 s)
make features                            # geometry, ESM, ProteinMPNN caches
make ladder                              # every rung, each writing reports/<name>/
make report                              # THE results table, all runs on one truth
make errors                              # slice tables and diagnostics
make align                               # verify each mutation is where we index it
make test                                # split-integrity and harness tests
```

`scripts/final_table.py` produces the results table in this README.
`data/folds.csv` is committed and frozen — nothing downstream regenerates it.

## Hardware and runtime

Development: **Intel Core i7-8650U, 4 cores @ 1.9 GHz, 8 GB RAM, no GPU**, Windows 10.
Neural training: **Colab T4**, driven from the CLI in `experiments/protattba_repro/`.

| Step | Where | Wall clock |
| --- | --- | --- |
| `src.data` — parse, verify 2,109 positions, dedup | CPU | ~65 s |
| `src.splits` — 1,431 pairwise alignments + leakage report | CPU | ~28 s |
| `src.features.geometry` — Shrake-Rupley over 54 complexes | CPU | ~5.5 min |
| ESM-2 650M per-residue, 448,772 tokens | T4 | ~4 min (1,998 tok/s) |
| the same | CPU | ~160 min |
| ProteinMPNN per-residue, 54 complexes | CPU | ~7 min |
| one forest rung, 5 folds × 3 seeds | CPU | ~20 s |
| one network configuration, 5 folds × 3 seeds | T4 | ~25 min |
| the full neural ladder as run (~30 configurations) | T4 | ~14 h |
| `pytest tests` | CPU | ~9 s |

Colab sessions are reclaimed after roughly an hour, which is shorter than several runs. The
harness resumes at `(fold, seed)` granularity and `experiments/protattba_repro/supervise.sh`
rebuilds a reclaimed session and relaunches its queue unattended.
