# Environment for the ProtAttBA reproduction. Deliberately separate from the project's own
# requirements.txt: the torch pin differs, and nothing here should reach the main ladder.
#
# ProtAttBA asks for python==3.10, pytorch==2.1.2, pytorch-cuda=11.8. That is honoured here.
# Two notes on why these exact versions:
#
#  * torch 2.1.2 is both their pin and the only workable choice on this machine. The project
#    already found that torch >= 2.5 fails to import with WinError 1114 on c10.dll because the
#    MSVC runtime is 14.28 and those builds need >= 14.40 (see the project requirements.txt).
#  * the cu118 build runs on this box's 461.40 / CUDA 11.2 driver via CUDA minor-version
#    compatibility, which is worth knowing but does not rescue the 2 GB GTX 1050 -- the run
#    itself needs a bigger card. See colab_job.py.
#
# Only the packages the S1131 code path imports are listed. Their requirments.txt also pins
# xgboost, matplotlib, seaborn, llvmlite, rjieba, progressbar2, lxml and protobuf, none of
# which src_s1131, model_module or utils touch.
#
#   python -m venv .venv_protattba
#   .venv_protattba/Scripts/pip install torch==2.1.2 --index-url https://download.pytorch.org/whl/cu118
#   .venv_protattba/Scripts/pip install -r requirements_protattba.txt
